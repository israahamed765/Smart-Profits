# P12.2 — Backend migration

**Date:** 2026-08-23  
**Rule:** gradual physical split. No deleted routes. No copied Financial Engine / Smart Guard / adapters. No cookie flag rewrite.

---

## Wave 1 (this phase) — migrated onto the standalone backend

These handlers live in `backend/src/http/*` and go **HTTP → service re-export → existing `server/services` → repository/core**. Next.js `app/api/*` for the same paths is a compatibility layer (in-process same handler, or `BACKEND_URL` proxy).

| Method | Path | Service | Why this wave |
| --- | --- | --- | --- |
| GET | `/api/workspace` | `workspace.service` | read, no Set-Cookie |
| POST | `/api/workspace` | `workspace.service` | write under `session.email` |
| POST | `/api/track` | `track.service` | optional session, low sensitivity |
| POST | `/api/analyze` | `analyze.service` | parser stays on server; rate limit kept |

Browser call sites for these three product paths use `apiFetch` in `lib/api/client.ts`. Default `NEXT_PUBLIC_API_BASE_URL` is empty → same-origin Next `/api/*`.

---

## Not migrated (still Next.js only)

Do **not** move these until Wave 1 stays green and cookie/CORS design is accepted.

| Area | Paths | Why not this wave |
| --- | --- | --- |
| Auth | `/api/auth/login`, `register`, `logout`, `me`, `profile`, `forgot-password`, `reset-password` | Set-Cookie / SMTP; cookie attach still uses Next `NextResponse` |
| Admin | `/api/admin/login`, `logout`, `me`, `snapshot`, `users` | `sp_admin` + `middleware.ts` |
| Smart Guard | `/api/smart-guard/evaluate`, `logs`, `demo` | fail-closed + NaC |
| Step-Up | `/api/smart-guard/step-up`, `send`, `verify` | identity + network code |
| NAC mock | `/api/nac*` | CSRF-exempt CAMARA surface; no domain service |

**Count:** 30 HTTP handlers total. Wave 1 covers **4 product handlers** (+ `/health`). **26** remain on Next.

---

## Request chain (migrated)

```text
Browser
  → lib/api/client.ts  (credentials: include; public base URL only)
  → Next /api/*  (default)  OR  localhost:4000  (if NEXT_PUBLIC_API_BASE_URL set)
      → maybeProxyToBackend  if BACKEND_URL is set
      → backend/src/http/*  (CORS on the standalone process only)
          → backend/src/services/*  (re-export)
              → server/services/*
                  → repositories / financial-engine core / parser
```

Forbidden: Frontend → Postgres / JSON `data/` / filesystem.

---

## Compatibility (P12.2.6)

Next routes are **not** deleted. Tests import `GET`/`POST` from `app/api/workspace|track|analyze/route.ts` and still pass.

| Mode | When | Cookies |
| --- | --- | --- |
| In-process | `BACKEND_URL` unset (tests, current Vercel) | host-only on the Next origin |
| BFF proxy | `BACKEND_URL` set on the Next process | browser still hits Next; cookies stay |
| Direct backend | `NEXT_PUBLIC_API_BASE_URL=http://localhost:4000` | requires **same cookie host** (`localhost`, not `127.0.0.1`) |
