## P12.3.2 Cookie design (chosen)

**Preferred production model: same-site BFF.**

Browser keeps calling Next `/api/auth/*` (`NEXT_PUBLIC_API_BASE_URL` empty). Cookies stay **host-only** on the UI host. Next may proxy with `BACKEND_URL` and forward `Set-Cookie`. No `Domain`. No `SameSite=None`.

**Local two-process (optional):** UI `http://localhost:3000` and API `http://localhost:4000` share host `localhost`, so host-only cookies are sent. `127.0.0.1:4000` is a **different host** and is not used as a cookie workaround.

Rejected: wide `Domain`, `SameSite=None`, `localStorage` sessions, `*` CORS.
