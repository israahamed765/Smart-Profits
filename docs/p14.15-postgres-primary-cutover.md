## Command

```bash
npm run db:cutover
```

Refuses unless the write-freeze flag is present **and** `verifyFinal` is GO. Does **not** unfreeze. Does **not** INSERT/UPDATE/DELETE catalogs. Does **not** run `db:reconcile` or `db:backfill`.

## Read contract

| Catalog | PostgreSQL reachable | PostgreSQL down (`queryPostgres` → `null`) |
| --- | --- | --- |
| merchants | return PG rows (including empty) | JSON shadow |
| workspaces | return PG row / list (no on-read backfill) | JSON shadow |
| track_events | return PG rows (including empty) | JSON shadow |
| guard_decisions | already PG-first | JSON file fallback (unchanged) |

Write order is unchanged (P14.4 dual-write).
