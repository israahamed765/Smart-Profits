## Command

```bash
npm run db:reconcile-frozen
```

Do **not** use `db:backfill` or a random `db:reconcile`. Those unfreeze in `finally` and cannot hold a consistent cutover window.

On **GO** this command **leaves the write-freeze engaged**. Use `npm run db:unfreeze` only to abort. On **NO-GO** the freeze is released.

## Rules (same as P14.13)

- Newer trusted ISO `savedAt` / `lastActive` wins. Equal or non-ISO → unresolved (NO-GO).
- Insert valid JSON-only Guard IDs into PG. Do not DELETE PG-only. Do not copy PG-only into JSON.
- Freeze-time PG-only IDs become the documented leftover set for this verify pass.
- UUID event rows whose payload matches JSON are not duplicates. Do not rewrite ids.
