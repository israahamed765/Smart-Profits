## P12.4.1 Audit (before)

| Endpoint | Auth | Service | Notes |
| --- | --- | --- | --- |
| POST `/api/admin/login` | none (middleware skip) | `loginAdmin` (env `ADMIN_EMAIL` / `ADMIN_PASSWORD`, timing-safe) | Set-Cookie `sp_admin` |
| POST `/api/admin/logout` | cookie clear | none | clears `sp_admin` only |
| GET `/api/admin/me` | `requireAdmin` | none (session payload) | `{ admin: { email, name } }` |
| GET `/api/admin/snapshot` | `requireAdmin` | `adminSnapshot` → user/workspace/event repos | facts without parseResult transactions |
| POST `/api/admin/users` | `requireAdmin` | `patchMerchantAccount` | body.email is the **merchant being patched**, not admin identity |

There is **no** `GET /api/admin/users`. The live contract is **POST**. It was not invented.

**Create `sp_admin`:** login → `createAdminToken` (role `admin`, 2 days) → Set-Cookie.  
**Verify:** `readAdminSession` (cookie name + HMAC + `role === "admin"`). Next `middleware.ts` also checks `/api/admin/*` except login. Backend handlers call `requireAdmin` because middleware does not run on the standalone process.  
**Delete:** logout → `Max-Age=0`. Stateless HMAC, same as merchant.  
**Role:** payload `role: "admin"`. Merchant `sp_session` is ignored.  
**Secrets:** `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_NAME`, `SESSION_SECRET` — server only.

---

## Cookie design

Unchanged flags: name `sp_admin`, httpOnly, SameSite=Lax, host-only (no Domain), Secure in production, maxAge 2d.

Preferred path: Next BFF (empty `NEXT_PUBLIC_API_BASE_URL`). Serialization uses `appendAdminSessionCookie` / `clearAdminSessionCookie` in `session-core` (one HMAC). Admin logout does **not** clear `sp_session`.

Rejected: `SameSite=None`, wide `Domain`.
