# P14.17 — Remove JSON Shadow

**Date:** 2026-08-26  
**Scope:** Archive the PostgreSQL-backed JSON catalogs **outside** `data/`, verify the archive, then delete those catalogs from `data/` while the P14.14R write-freeze remains engaged. Dual-write code is unchanged (P14.18). `appendEvent` still mints `randomUUID()`. **`nac-demo.json` is not archived or deleted.** PostgreSQL is not modified.

```text
P14.16 Shadow validation         GO, freeze held
   ↓
P14.17 Remove JSON shadow        ← this document
   ↓
P14.18 PostgreSQL-only catalogs  (JSON fallback removed; freeze held)
```

---

## Command

```bash
npm run db:archive-and-remove-json
```

Refuses unless freeze, the P14.15 cutover marker, and the P14.16 shadow-validation marker are present, live `verifyFinal` is GO, the archive is outside `data/` and matches live catalogs, and JSON fallback is not required. Does **not** unfreeze. Does **not** INSERT/UPDATE/DELETE PostgreSQL. Does **not** delete `nac-demo.json`. If post-delete SELECT verification fails, catalogs are restored from the archive.
