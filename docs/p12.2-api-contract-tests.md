# P12.2 — API contract tests

**Date:** 2026-08-23  
**Files:** `tests/backend-contract.test.ts`, `tests/backend-vertical-slice.test.ts`, `tests/csrf.test.ts`, `tests/authorization-idor.test.ts`

Contract means: same status, same `{ error }` / `{ ok }` / `{ workspace }` / `{ parsed, result }` shapes as the Next handlers. Tests call **both** Next route modules and `backend/src/http/*`, plus a live `node:http` process.

---

## Covered (Wave 1)

| Check | Expected |
| --- | --- |
| GET `/api/workspace` no cookie | **401** `يجب تسجيل الدخول أولاً.` Next = backend |
| GET `/api/workspace` `sp_admin` only | **401** (admin ≠ merchant) |
| GET `/api/workspace` valid `sp_session` | **200** `{ workspace }` |
| POST `/api/workspace` no Origin | **403** CSRF |
| POST `/api/workspace` user A then GET user B | B does not see A’s `fileName` (IDOR) |
| POST with `ownerEmail` of another user | still stored under **session.email** |
| POST `/api/track` no Origin | **403** |
| POST `/api/track` with frontend Origin | **200** `{ ok: true }` |
| POST `/api/analyze` no session, Origin present | **401** |
| Standalone `/health` | **200** `{ ok: true }` |
| Error JSON | no `stack`, no `SESSION_SECRET`, no connection strings |
| `apiUrl("/api/workspace")` with empty public base | `/api/workspace` (same-origin) |

## CORS (standalone process only)

| Check | Expected |
| --- | --- |
| Origin = `FRONTEND_ORIGIN` / `APP_URL` | echo that origin; `Allow-Credentials: true` |
| Origin = `https://evil.example` | no `Access-Control-Allow-Origin`; still **401** on workspace |
| OPTIONS allowed origin | **204** |
| OPTIONS unknown origin | **403**, no `*` |
| CORS + no cookie | still **401** (CORS is not authorization) |

## CSRF across ports

`Origin: http://localhost:3000` + `Host: localhost:4000` is **allowed** via `APP_URL` / `FRONTEND_ORIGIN` hosts (`server/middleware/csrf.ts`). Evil origin on the backend host is still **403**.
