## Baseline (locked)

| Item | Status |
| --- | --- |
| Product migration | `server/db/migrations/001_current_schema.sql` only |
| Id | filename `001_current_schema.sql` |
| Duplicates | none |
| Order | numeric prefix, `001` first |
| History | `schema_migrations` created by the **runner**, not by 001 |
| Apply | `BEGIN` → SQL → `INSERT schema_migrations` → `COMMIT` |
| Failure | `ROLLBACK`; id not applied |
| Invoke | `npm run db:migrate` only |

001 product objects: `merchants`, `workspaces`, `track_events`, `guard_decisions`, plus the three indexes from P14.4/P14.5. Payload columns remain `JSONB`. No FKs, no `UNIQUE(phone)`, no `INSERT` backfill.

`schema_migrations` is **runner bootstrap** (`server/db/migrate.ts`). It is not duplicated inside 001. That split is intentional and locked.
