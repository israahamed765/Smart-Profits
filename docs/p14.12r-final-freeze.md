## How every mutation path was found

All durable writes of the four catalogs go through **repositories** (P14.4). HTTP and the Next BFF never import `pg` / json-store / repositories.

| Catalog | Repository write | HTTP / other callers (stopping the UI is not enough) |
| --- | --- | --- |
| merchants | `upsertAccount`; on-read `writeAccountPg` when PG is empty | `POST /api/auth/register`, `login` (lastActive), `forgot-password`, `reset-password`, `POST /api/auth/profile`, `POST /api/admin/users`, Smart Guard evaluate (freeze flags on the account) |
| workspaces | `saveWorkspace`; on-read backfill from `loadWorkspace` | `POST /api/workspace`; `GET /api/workspace` **can write** via backfill |
| track_events | `appendEvent`, `mergeEvents` (JSON only, unused by HTTP) | `POST /api/track` |
| guard_decisions | `appendGuardDecision` | `POST /api/smart-guard/evaluate` (and related Guard persist). PG-first; JSON only if the insert returns `null` |

`nac-demo.json` is JSON-only and is **not** part of this freeze.

## How freeze works

File flag (default `data/.p14.12r-write-freeze`). Tests isolate via `SMARTPROFIT_FREEZE_PATH`.

```text
engageWriteFreeze()
   ↓
assertProductWrite() at the start of upsertAccount / saveWorkspace /
appendEvent / mergeEvents / appendGuardDecision
   ↓
AppError 503  "التخزين مجمّد للتحقق النهائي من البيانات."
```

On-read backfill is **skipped** while frozen (no silent INSERT), reads still use the P14.4 order.

Operator `server/db/freeze-plan.ts` does **not** call `assertProductWrite`. It may `INSERT … ON CONFLICT DO NOTHING` for missing keys only. **No `DO UPDATE`. No DELETE.**

Event copy: skip insert when any PG **payload** already hashes to `sha256(NUL-join("smartprofit.track_event.v1", at, type, label, email))`. Existing UUID ids are left untouched.

```bash
npm run db:freeze    # freeze → snapshot → plan → copy-missing → re-plan → mutation probe → unfreeze
npm run db:unfreeze  # remove the flag if a run is interrupted
```

Snapshot directory: `.p14.12r-snapshot/` (gitignored). Live `data/` is copied, not rewritten.

Conflicts (extra keys, overlapping payload mismatch) **abort the copy**. Freeze is not used to hide them.

---

## What freeze does not do

- Change API JSON contracts (still `{ error }` on AppError)
- Change Auth / cookies / CSRF / CORS
- Change Financial Engine or Guard **policy** (Guard persist rethrows freeze instead of swallowing it)
- Delete JSON or stop dual-write
- Make PostgreSQL the read primary
