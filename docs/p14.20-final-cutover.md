## Cutover window

`npm run db:final-cutover` refuses unless every pre-lift gate passes:

- Write-freeze is engaged
- P14.19 operational marker is valid (`freezeLifted: false`)
- P14.17 removal marker is valid
- Archive is present, outside `data/`, and unchanged
- `data/` has no catalog JSON; `nac-demo.json` is present
- PostgreSQL is reachable; `001_current_schema.sql` is applied
- Catalog tables exist; repository reads succeed
- Product writes are still rejected while frozen
- Live counts match the P14.19 marker
- Catalog repositories remain PostgreSQL-only

Only then it **lifts the freeze**, writes a probe merchant / workspace / event / guard through production repositories, reads them back, deletes **only** `p14.20-cutover-probe@store.test`, and stamps `data/.p14.20-final-cutover`.

If the write window fails, the probe is deleted and the freeze is **restored**. The archive is never deleted.
