# P14.18 — Remove Dual-Write / JSON Fallback

**Date:** 2026-08-28  
**Scope:** PostgreSQL is the **only** runtime store for merchants, workspaces, track_events, and guard_decisions. Dual-write and JSON fallback are removed from those repositories. `nac-demo.json` stays JSON-only. The P14.17 archive is not a runtime fallback and is not deleted. The write-freeze remains engaged. `appendEvent` still mints `randomUUID()` for new PostgreSQL rows. Existing event IDs are not migrated.

```text
P14.17 Remove JSON shadow        GO, freeze held, catalogs archived
   ↓
P14.18 PostgreSQL-only catalogs  ← this document
   ↓
P14.19 operational verification  (freeze held; no cleanup)
```

---

## Production contract

| Catalog | Read | Write | On PostgreSQL failure |
| --- | --- | --- | --- |
| merchants | `SELECT payload FROM merchants` | upsert `merchants` | throw |
| workspaces | `SELECT` by email / list | upsert `workspaces` | throw |
| track_events | `SELECT payload … LIMIT 2000` | `INSERT … randomUUID()` | throw |
| guard_decisions | `SELECT * … LIMIT` | `INSERT` columns | throw |
| demo flags | `nac-demo.json` | `nac-demo.json` | n/a (not a PG table) |

`queryPostgres` still swallows driver errors (null + 30s backoff). Catalog repositories call `requirePostgres` and **throw** instead of reading `data/` or `.p14.17-json-archive/`.

---

## Not in this slice

- `db:unfreeze`
- Delete `.p14.17-json-archive/`
- Delete `nac-demo.json`
- API / cookie / CSRF / Financial Engine / Guard policy changes
- Event payload shape (`type`, `at`, `label?`, `email?`)
- Frontend localStorage
