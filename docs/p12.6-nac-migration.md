## After architecture

```
Frontend (optional NEXT_PUBLIC_API_BASE_URL)
  → Next /api/nac/* BFF (maybeProxyToBackend)
  → Backend /api/nac/*
  → server/services/nac.service (thin) → nokia-mock / simulator
```

Default: empty public API base + empty `BACKEND_URL` → Next runs the backend handler in-process.

## Auth boundary

Unchanged: **no session** on `/api/nac/*`. Forged `sp_session` is ignored. Simulator email comes from `x-merchant-email` / mock-gate `body.email` only (pre-existing demo identity, not merchant auth).

## Cookies

Unchanged: `sp_session` / `sp_admin`, httpOnly, SameSite=Lax, host-only. NAC does not set cookies.

## CORS

Same P12.2–P12.5 allowlist. Never `*`. Credentials with exact origin. OPTIONS foreign origin → 403.

## CSRF

Existing skip `path.startsWith("/api/nac")` **kept** (not added, not removed). NAC POST without Origin → **200** (previous behavior). Guard/Auth POST without Origin → **403**.

## Secrets

Still only `server/smart-guard/nac-env.ts`. No `NEXT_PUBLIC_NAC_*`. HTTP `/api/nac` always simulator; live RapidAPI stays inside Smart Guard `nac-client`.

## Mock / simulator

`nokia-mock.ts`, `nac-simulator.ts`, `nac-client.ts` **not behavior-changed**. Import path for `SIM_SWAP_MAX_AGE_HOURS` in the new service/handler uses `@/shared/contracts/nac-contract` (same constant) so standalone `tsx` can load named exports.

## Fail-Closed

- Mock gate dummy `+99999991000` → `freeze` / not Allow.
- Malformed mock-gate JSON → 500 `"Nokia mock gate failed."` / not Allow.
- Live NaC throw still surfaces as evaluate **503** freeze/`check_failed` (P12.5 contract, re-tested in `backend-nac.test.ts`).
